
📊 Olist E-Commerce Sales Analysis
📌 Project Overview
This project presents an interactive E-Commerce Sales Analysis Dashboard built using Microsoft Power BI.

The objective of this project is to analyze sales performance, customer behavior, seller performance, product categories, payment methods, geographical revenue distribution, and monthly revenue trends.

The project uses SQL for data analysis, Power Query for data transformation, and DAX for creating analytical measures and KPIs.

🎯 Business Objectives
Analyze overall sales performance
Track revenue and order performance
Identify top customers and sellers
Analyze revenue by product category
Analyze revenue across customer states
Understand payment method distribution
Track monthly revenue trends
Analyze Average Order Value
Analyze average delivery time
