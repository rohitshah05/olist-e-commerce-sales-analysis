# Olist E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset using SQL Server and Power BI to understand sales performance, customer behavior, seller performance, product categories, payment methods, and delivery performance.

The project includes SQL-based data analysis and an interactive Power BI dashboard to generate meaningful business insights.

## 🎯 Business Objectives

- Analyze overall sales performance
- Identify top-performing product categories
- Analyze customer and seller performance
- Understand payment method preferences
- Analyze revenue across Brazilian states
- Track monthly revenue trends
- Analyze delivery performance

## 📊 Key Performance Indicators

## 💡 Key Insights

- Total revenue was approximately R$13.59 million.
- The dataset contains 99,441 orders.
- Credit Card was the most preferred payment method.
- Beleza Saúde was among the highest-revenue product categories.
- Revenue varied across different Brazilian states.
- A small number of sellers contributed significantly to overall revenue.
- Average estimated delivery time was approximately 9 days.
